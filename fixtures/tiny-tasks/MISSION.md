# Tiny Tasks Mission

实现一个本地任务清单网页，使用简单前端和 localStorage，不接商业服务。

## 必须实现

- 新增、编辑、删除任务
- 完成状态切换
- 全部 / 未完成 / 已完成筛选与计数
- 刷新后保留任务、名称和完成状态
- 中文任务名
- 不允许提交仅空格或空名称

## 固定验收点（不得删除或弱化）

1. 创建「买牛奶」和「检查报告」，完成其中一项。
2. 三种筛选结果和计数正确。
3. 编辑中文名称后不改变完成状态。
4. 刷新后任务、名称和完成状态保留。
5. 删除已完成任务后，计数和空状态正确。
6. 不允许提交仅空格名称。

`skipScrutiny` 与 `skipUserTesting` 必须保持 false。
